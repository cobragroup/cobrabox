# Decompositions

*How do I decompose my signal into components?*

Features in the `cobrabox.decompositions` domain. Access them as `cb.decompositions.<Feature>` or `cb.feature.<Feature>`.

### EMD
Decompose a signal into Intrinsic Mode Functions (IMFs) using Empirical Mode Decomposition.

**Tags:** [`data-driven`](../tags/data-driven.md), [`nonlinear`](../tags/nonlinear.md), [`intrinsic-mode-functions`](../tags/intrinsic-mode-functions.md), [`time-frequency`](../tags/time-frequency.md), [`nonstationary`](../tags/nonstationary.md), [`eeg`](../tags/eeg.md), [`io:adds-dimension`](../tags/io-adds-dimension.md)

### SVD
Compute truncated SVD over one dimension.

**Tags:** [`dimensionality-reduction`](../tags/dimensionality-reduction.md), [`patterns`](../tags/patterns.md), [`eeg`](../tags/eeg.md), [`io:matrix`](../tags/io-matrix.md)
